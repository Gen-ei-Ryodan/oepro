# OEPRO E-Commerce Demo (Buyer-Side Experience)

Proyek demo web store e-commerce brand fashion **OEPRO** (OEPRO Cotton Basic / Oepro Store), berfokus pada pengalaman belanja pembeli (*buyer-side*).

## Struktur Direktori
- `docs/` : Dokumen PRD dan Backlog Sprint proyek.
  - `PRD_OEPRO_BUYER_SIDE.md` : Dokumen spesifikasi fungsional dan kebutuhan fitur.
  - `SPRINT_BACKLOG_OEPRO.md` : Rincian tiket sprint dan pembagian tugas tim dev.
- `src/` : Source code aplikasi frontend web store.
- `public/` : Aset statis, font, dan gambar produk.
